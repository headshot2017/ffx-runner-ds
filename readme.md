# FFX Runner DS

Recreation / de-make of the web browser game [FFX Runner](https://github.com/OfficinePixel/ffx_runner) to the Nintendo DS
Made using [BlocksDS](https://blocksds.skylyrac.net/)

Still W.I.P.
